ShopOps Data Agent (Natural Language to SQL & Metrics)

Olist Brezilya E-Ticaret Veriseti (9 Tablo, 99.441 Sipariş) üzerinde Semantik Katman (metrics.yaml) destekli güvenli sorgulama motoru.

Örnek Sorgular:
Semantik Katman Eşleşmesi (metrics.yaml) Verified Metric
Metric Name: late_delivery_rate_by_category
Target Schema: olist_orders, olist_order_items, olist_products
Date Range Filter: order_purchase_timestamp BETWEEN '2018-01-01' AND '2018-12-31'
Üretilen Güvenli SQL Sorgusu (Read-only) Dialect: SQLite / PostgreSQL 
SELECT 
    p.product_category_name AS kategori,
    COUNT(o.order_id) AS toplam_siparis,
    ROUND(AVG(JULIANDAY(o.order_delivered_customer_date) - JULIANDAY(o.order_estimated_delivery_date)), 2) AS ort_gecikme_gun
FROM olist_orders o
JOIN olist_order_items i ON o.order_id = i.order_id
JOIN olist_products p ON i.product_id = p.product_id
WHERE o.order_delivered_customer_date > o.order_estimated_delivery_date
  AND strftime('%Y', o.order_purchase_timestamp) = '2018'
GROUP BY 1
ORDER BY ort_gecikme_gun DESC
LIMIT 3;

ShopOps Mimarisi & Rehber Yanıtları

Neden Agent? (Sabit Akış vs Agent)

Müşteri talepleri deterministik olmayan yollar izler. Bir talep tek bir tool çağrısıyla çözülürken, bir başkası iade kontrolü, gecikme hesabı ve insan onayı gerektirir. Model, ReAct döngüsünde anlık gözlemlere göre adımları dinamik belirler.

Güvenlik ve Yetkilendirme (HITL & Tool Sandbox)

Yetkilendirme kuralları sistem promptuna güvenilerek yapılmaz; tool seviyesinde tipli parametre doğrulaması ile kontrol edilir. Veritabanını değiştiren tüm yazma aksiyonları (iade_talebi_olustur) insan onayına (Human-in-the-Loop) tabidir.
